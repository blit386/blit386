## What happens after you paste

1. Your AI writes one HTML file. No install, no account.
2. If your AI can show it, play it right there. If not, save it as `game.html` and open it in your browser.
3. Ask for changes: "make it faster", "add a high score".

## Small on purpose

256 colors and a pixel grid. The limits are why a first game looks deliberate and gets finished.

BLIT386 draws with numbered colors instead of picking a color for every pixel. Change what color 3 means and everything
drawn in it changes at once: water flows, the sky goes dark, a hit flashes red, and not one pixel is drawn again.

## For developers

BLIT386 is a palette-first retro game engine for the web, written in TypeScript with no dependencies. All drawing goes
through an [indexed palette](/docs/guides/palette) of up to 256 entries, with
[palette cycling, fades and swaps](/docs/guides/palette) for classic effects. [WebGPU](/docs/api/rendering) renders
where the browser has it, with an automatic Canvas 2D fallback where it does not. It covers
[sprites, primitives and bitmap text](/docs/api/assets), [pointer, keyboard and gamepad input](/docs/guides/input),
[audio with a mixer and a synth](/docs/guides/audio), and a [debug overlay](/docs/api/overlay).

Start a project with the scaffolder. It works with npm, pnpm, yarn, or bun and sets up a Vite project with the engine, a
starter game, and docs for your coding agent:

```bash
npm create blit386@latest my-game
```

Or skip the install: [one HTML file](/docs/guides/single-file) loads the engine from a CDN.
[Getting Started](/docs/getting-started) covers both.
