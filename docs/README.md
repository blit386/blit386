# BLIT386 Docs

The published version of these docs lives at [blit386.dev/docs](https://blit386.dev/docs).

Edit sources here first. The `blit386-dev-fumapress` sibling repo mirrors the pages listed in `_sitemap.json` to the
live site. Run `pnpm run sync:doc-banners` after adding a doc to the sitemap. Contributor-only pages (not in the
sitemap: `developer-experience-guide.md`, `voice.md`, `tooling.md`, `security/`) stay plain Markdown and do not appear
on the site.
